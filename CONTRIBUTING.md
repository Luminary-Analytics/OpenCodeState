# Contributing to OpenCodeState

OpenCodeState is an architecture-first open-source project. Early contributions should focus on clarifying the model, sharpening the primitives, improving the RFCs, and helping define the first reference implementation.

## Project Mission

OpenCodeState exists to define a new standard for software state management in the AI-native era.

The north star is:

> Source control should be invisible until human judgment is required.

## How to Contribute

Good early contributions include:

- Improving the manifesto
- Challenging assumptions in the RFCs
- Proposing better primitive names
- Adding examples of sessions, packages, checkpoints, or provenance
- Suggesting implementation approaches
- Identifying risks or edge cases
- Building prototypes for local checkpointing, event capture, or package generation

## RFC Process

OpenCodeState uses RFCs to discuss major design decisions.

An RFC should explain:

- The problem being solved
- The proposed design
- Alternatives considered
- Tradeoffs
- Open questions
- Impact on users, implementers, and compatibility adapters

RFCs live in the `rfcs/` directory.

## Development Principles

Contributions should align with the founding principles:

1. Human-first, not command-first
2. Continuous protection
3. Intent over syntax
4. Packages over commits
5. Semantic integration
6. AI-native provenance
7. Local-first by default
8. Open protocol
9. Git bridge, not Git dependence
10. Interrupt only for judgment

## Code of Conduct

This project should be welcoming, direct, and intellectually honest.

Debate the architecture aggressively, but treat contributors respectfully.
